# 🧠 Real-Time Crypto Market Analytics Pipeline

### End-to-End Streaming, Machine Learning, and Dashboarding System on Azure Databricks + Snowflake

---

## 🚀 Project Objective

Design and deploy a **real-time crypto market analytics pipeline** that continuously ingests live cryptocurrency prices, processes and aggregates them, predicts next-minute prices using ML models, and visualizes insights in interactive dashboards.  
This project demonstrates a **production-grade, multi-cloud architecture** integrating **Azure Event Hubs**, **Databricks**, **Delta Lake**, **Snowflake**, and **MLflow** — simulating how top data teams build streaming intelligence systems.

---

## 🧩 Architecture Overview

### 🔁 Data Flow

1. **Producer (Python):**
   - Fetches crypto prices (BTC, ETH, SOL, XRP, LTC) from Alpha Vantage API.
   - Sends events to **Azure Event Hub** every 30 seconds.
   - Automatically switches to simulated data if API hits rate limits.

2. **Consumer (Databricks):**
   - Reads the live event stream using **Spark Structured Streaming**.
   - Parses, cleans, and timestamps events.
   - Stores them in **Bronze → Silver → Gold** Delta tables.

3. **Machine Learning:**
   - Builds time-series regression models per coin (BTC, ETH, SOL, LTC, XRP).
   - Tracks experiments with **MLflow**.
   - Predicts next-minute closing prices and writes to **Gold Delta** layer.

4. **Data Warehouse (Snowflake):**
   - Delta Gold data is published to Snowflake for analytics.
   - Snowflake dashboards show KPIs like prediction accuracy, gain opportunity %, and momentum indicators.

5. **Visualization:**
   - Dashboards in **Snowsight** show predicted vs. actual prices, accuracy, and last sync time.
   - Ready for integration with Power BI / Grafana for real-time visualization.

6. **Automation (Future Step):**
   - Use **Apache Airflow** to orchestrate retraining and refresh predictions automatically.

## 🧮 Machine Learning Methodology

- **Input Features:**
  - Rolling averages, volatility, deltas (high-low-open-close).
- **Target Variable:**  
  - `target_next_close` → next-minute close price.
- **Models:**  
  - Separate regression model per coin using PySpark MLlib.
- **Metrics:**
  - MAPE (Mean Absolute Percentage Error) → converted into model accuracy %.
- **Tracking:**  
  - All models tracked via **MLflow experiments**.

## 📊 Snowflake Dashboard Insights

These Snowflake dashboards represent the **final analytical layer** of the real-time crypto prediction pipeline.  
They visualize live predictions, confidence scores, and momentum indicators generated by Databricks ML models for multiple cryptocurrencies.

---

### 🧮 1️⃣ Model Accuracy — All Coins (%)

This chart highlights the **prediction accuracy of each coin’s ML model**, calculated using Mean Absolute Percentage Error (MAPE).

- Models are built and tracked per coin in **Spark MLlib + MLflow**.
- Accuracy values above **97–99%** reflect consistent, low-error performance.
- Differences between coins show how volatility affects prediction accuracy:
  - **BTC (99.83%)** and **XRP (99.71%)** → High model stability.  
  - **LTC (97.75%)** and **SOL (98.78%)** → Slightly more volatile.

📌 **Insight:** Demonstrates **multi-model monitoring** and performance tracking directly inside Snowflake dashboards.

---

### 🎯 2️⃣ Confidence Zone

Displays the **average predicted close value (`AVG_PRED`) per cryptocurrency**, representing the model’s confidence in its next prediction window.

- Extracted from the **Gold Delta layer** written by Databricks.
- Visualizes steady-state or “most likely” price zones per coin.
- Can serve as a **buy/sell threshold indicator** or confidence range.

📌 **Insight:** Highlights integration of **ML prediction confidence metrics** directly into a live Snowflake data warehouse.

---

### 📈 3️⃣ Momentum Indicator

The **Momentum Signal** chart visualizes predicted short-term trend direction:

- Computed using `MOMENTUM_SIGNAL`, a derived metric comparing predicted and actual deltas.
- **Positive (+1 to +6)** → Expected upward trend (bullish signal).  
- **Negative (−1 to −6)** → Expected downward trend (bearish signal).  
- Built dynamically using **Snowflake SQL views** refreshed on schedule.

📌 **Insight:** Represents **financial signal engineering** — translating ML outputs into actionable momentum indicators.

### 📉 5️⃣ BTC – Prediction Error (%) Over Time

This graph visualizes the **model’s rolling prediction error** for BTC over time.

Formula used:
\[
\text{Percent Error} = \frac{|Target - Prediction|}{Target} \times 100
\]

- Spikes show short-term volatility or moments when the API fallback (simulated data) was triggered.
- Smooth intervals indicate high model reliability and market stability.

📌 **Insight:** Demonstrates **model drift monitoring** and reliability tracking for real-time ML forecasting.
